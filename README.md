# Omes wears

The official online store for Omes wears, offering handmade shoes, bags and easy wears.

## Development
- Install dependencies: `npm install`
- Run locally: `npm run dev` then open http://localhost:3000
- Build for production: `npm run build`

## Where content lives
- Store details (contact, payment): `lib/config.ts`
- Products: `lib/products.ts`
- Product images: `public/products/`

## Deployment
Hosted on Netlify, deployed automatically from this repository.
